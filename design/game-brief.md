# Game Brief: 봄빛 뽑기 농장 (Spring Gacha Farm)

## In your words
식물 키우기 농장게임, 뽑기를 통해서 식물이나 동물들이 나오고 이런 애들을 농장에서 활용하거나 상점에서 다른 식물 씨앗으로 교환할 수 있어.
1. 재화: 작물을 팔아서 번 코인
2. 활용: 하나하나 능력이 있음. 닭이 알늘 낳거나. 식물을 빠르게 자라게 함.
3. 등급: 일반/에픽/희귀/전설/시크릿/신/신을 낳은 신/레전드 오브 레전드 이런 등급으로, 똑같은 걸 뽑으면 똑같은 애들은 합쳐서 능력이 더 강해지도록, 원하는 애들은 상점에서 팔고 코인을 얻을수 있음
4. 느낌: 느낌 평화롭고 봄 같은 느낌
5. 모습: 3인칭 시점으로. 그림체는 로블록스 그로우 어 가든 처럼
6. 난이도: 식물들이 심으면 알아서 잘 자라는 난이도
7. 목표: 끝없이 계속 키우기
8. 게임 한판

**Pitch:** 작물을 키워 판 코인으로 뽑기를 돌려 능력 있는 식물·동물을 모으고, 같은 것끼리 합쳐 키우며 '레전드 오브 레전드'까지 노리는 끝없는 봄 농장.

**Genre:** farming life sim + 뽑기(가챠)

**Controls:** 컴퓨터: WASD 걷기 · 마우스 드래그 카메라 회전 · 스페이스 심기/수확/배치/열기 · 1–0 손에 든 것 고르기 · T 도구 바꾸기 · F 전체화면 *(guessed)*. 태블릿: 왼쪽 아래 가상 조이스틱 · 오른쪽 빈 곳 드래그로 카메라 · 오른쪽 아래 큰 '행동' 버튼 · 핫바 칸 탭 · 도구 칸 탭으로 도구 바꾸기 · 메뉴는 큰 버튼 탭. 첫 터치에 터치 버튼이 나타남 *(guessed)*.

**Question:** 키우고 → 팔고 → 뽑고 → 합치는 고리가 10분 넘게 "한 번만 더"를 만드는가? *(guessed)*

**Hooks:** 8단계 등급 뽑기 + 같은 것끼리 합쳐 강해지는 능력 동물·식물이 농장 일을 거든다.

## First minute
봄 농장 한가운데에서 시작한다. 빈 밭 6칸과 씨앗 3개. 밭 앞에서 행동 버튼을 누르면 씨앗이 심기고 몇 초 만에 새싹 → 줄기 → 열매로 자라는 게 보인다. 익은 작물을 수확해 가게에 팔면 코인이 오른다. 첫 뽑기 비용이 모이면 뽑기 기계가 빛나며 부르고, 첫 뽑기는 닭(일반) 확정 *(guessed)*. 닭을 농장에 놓으면 곧 알을 낳고, 알을 주워 팔면 큰 코인이 들어온다: 훅의 첫 보상.

## Challenge
잃는 것은 없다: 작물은 심으면 알아서 자라고 죽지 않는다. 대신 고르는 재미가 커진다: 밭과 동물 자리가 제한되고, 뽑기 비용이 조금씩 오르며, 상위 등급일수록 확률이 낮다. 3–5분쯤 "팔까, 합쳐서 강화할까"가 처음 고민이 되고, 이후 밭 확장·고급 뽑기·시크릿 이상 등급이 기다린다 *(guessed)*.

## Core loop
- 씨앗을 심으면 알아서 자라고, 수확해 판다.
- 코인으로 뽑기를 돌려 등급 있는 식물·동물을 얻는다.
- 농장에 배치하면 능력(알 낳기, 성장 가속 등)으로 수입이 는다. 중복은 합쳐 강화, 필요 없는 건 팔아 코인.
- 늘어난 수입으로 더 비싼 씨앗과 더 높은 뽑기를 반복. 끝없음.

## Goal & fail state
- 목표 없이 끝없이 키운다. 한 판이 끝났다고 느끼는 때는 도감에 새 등급이 열렸을 때 *(guessed)*. 실패 없음; 자동 저장, 처음부터 다시 하는 초기화 버튼 *(guessed)*.
