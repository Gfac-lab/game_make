# Game Brief: 블록 미로 대난투 (Block Maze Brawl)

## In your words
> FPS게임 로블록스 느낌의 1인칭, 봇들이랑 사용자가 어려명이 일정한 맵에서 실시간으로 플레이 할 수 있게. 미로 같은 느낌의 맵으로 총은 스나이퍼, 라이플, RPG, 권총, 리볼버, 우지, 맨주먹, 낫, 칼, 수류탄, C4를 포함해줘

1. 경기 방식: 먼저 20킬, 개인전
2. 봇: 봇 난이도는 타이틀에서 선택할 수 있게
3. 무기: 무기는 열쇠로 구입, 열쇠는 경기 성적(킬)에 따라서 게임을 마치면 지급, 게임 시작 전에 무기를 열쇠로 해방하여 계속 사용할 수 있음. 처음에 기본 무기는 라이플, 권총, 주먹, 수류탄, 이후에 열쇠로 구입할 수 있게. 봇들은 랜덤으로 무기 사용
4. 손맛: 빠른 아레나식 전개
5. 겉모습: 로블록스 느낌의 블록
6. 난이도: 예시 그대로
7. 맵: 좁은 맵, 큰 맵 선택할 수 있게 맵을 2가지 타입으로 만들어줘 밝은 느낌으로
8. 슬라이스

**Pitch:** 밝은 블록 장난감 미로에서 봇 7명과 1인칭 개인전, 먼저 20킬이면 승리 — 번 열쇠로 새 무기를 영구 해금하고, 죽을 때마다 로드아웃을 다시 짠다.

**Genre:** first-person-shooter + competitive-multiplayer (봇 대전 아레나)

**Controls:** PC — WASD 이동 · 마우스 조준 · 좌클릭 공격 · 우클릭 줌 · Space 점프 · Shift 질주 · R 재장전 · 1~4/휠 무기 교체 · Esc 일시정지(감도) *(guessed)*. 태블릿 — 왼쪽 조이스틱 이동 · 오른쪽 드래그 시점 · 발사/점프/재장전/줌/무기 버튼 *(guessed)*

**Question:** 미로에서 매번 다른 무기를 든 봇들과 벌이는 빠른 개인전이 재밌고, 열쇠 해금과 죽을 때마다 고르는 로드아웃이 "한 판 더"를 부르는가?

**Hooks:** 11종 무기가 모두 다르게 손에 감김 + 경기 성적으로 열쇠를 벌어 무기 영구 해금 + 리스폰마다 로드아웃 교체

## Look and references
- Look: 밝은 플라스틱 장난감 블록 세상. 캐릭터는 사각 머리·몸통·팔다리의 블록 인형(봇마다 다른 원색 옷, 머리 위 "BOT" 이름표). 바닥은 매끈한 파스텔 크림 타일(은은한 체크), 미로 벽은 구역마다 다른 매끈한 파스텔 블록(하늘색·레몬·민트·코랄, 광장 기둥은 라일락) — 돌기·벽돌 줄눈 없는 매끈한 면, 레고 느낌 없음. 맑은 하늘색 배경. 무기도 각진 블록 장난감 형태. 시그니처: 피격 시 블록 파편, 처치 시 캐릭터가 블록 조각으로 흩어짐. every figure drawn, no emoji, no plain circles.
- References: 로블록스 계열 블록 슈터(블록 인형과 캐주얼 분위기), Krunker(브라우저 안의 빠른 1인칭 아레나)
- View: 3D · Camera: 1인칭(`first`), 마우스 직결 조준

## First minute
타이틀에서 봇 난이도(쉬움/보통/어려움)와 맵(좁은 미로/큰 미로)을 고르고, 무기고에서 보유 열쇠와 잠긴 무기를 본 뒤 4칸 로드아웃을 확인하고 시작한다. 미로 한쪽에서 라이플을 들고 스폰하며, 짧은 조작 안내가 3초간 떴다 사라진다(태블릿은 터치 버튼 안내). 30초 안에 첫 봇과 마주치고, 히트마커가 "틱", 킬 시 봇이 블록 조각으로 터진다. 처음 죽으면 로드아웃 화면이 뜨고, 다른 무기로 바꿔 다시 들어가는 순간 이 게임의 리듬을 안다.

## Challenge
첫 30초 안에 봇과 교전. 봇은 사람처럼 0.3~0.6초 늦게 반응하고 가끔 빗맞히며 벽 너머를 못 본다. 어려움 봇은 더 빠르고 정확하다. 죽으면 무기를 고르고(최소 3초) 나를 죽인 적과 먼 곳에서 리스폰. 픽업도 자동 회복도 없으므로 한 목숨의 체력 100이 전부다 — 리스폰해야 다시 찬다. 누군가 19킬이면 "매치 포인트". 봇은 처음부터 랜덤 무기(RPG·스나이퍼 포함)를 든다. *(inferred (strong))*

## Core loop
- 미로를 누비며 봇을 찾아 교전 → 킬 → 남은 체력으로 다음 교전을 고름
- 죽으면 로드아웃 다시 선택 → 리스폰
- 누군가 20킬 → 경기 종료 → 순위표 → 성적에 따라 열쇠 지급
- 무기고에서 열쇠로 무기 해금(영구 저장) → 재대결
- Leads: 경기 규칙·점수·리스폰·봇은 competitive-multiplayer, 조준·무기·피격 피드백은 first-person-shooter, 무기 경제와 로드아웃은 사용자 설계

## Goal & fail state
- 목표: 먼저 20킬 → 승리, 순위에 따라 열쇠 보너스
- 실패: 봇이 먼저 20킬 → 패배(그래도 내 킬 수만큼 열쇠 지급)
